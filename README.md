# ⚔ Skyrim Together Reborn — Co-op Launcher & Installer

Удобный автономный лаунчер-установщик и менеджер совместной игры для **The Elder Scrolls V: Skyrim Special Edition**.

---

## 🚀 Главные возможности

1. **Не требует Python:** Программа скомпилирована в единый переносимый файл `SkyrimCoopLauncher.exe`. Друзьям достаточно просто запустить его.
2. **Автопоиск игры:** Сам находит установленный Skyrim Special Edition на дисках и в Steam-библиотеках.
3. **Проверка совместимости:** Проверяет версию `SkyrimSE.exe` (требуется ветка 1.6+).
4. **Установка в 1 клик:**
   - Автоматически скачивает и ставит актуальный **Skyrim Together Reborn (v1.8.0)**.
   - Скачивает и ставит **Address Library for SKSE Plugins**.
   - Не портит оригинальные файлы игры (ведет манифест `str_manifest.json`).
5. **Сервер для хоста:**
   - Автоопределение IP-адреса в **Radmin VPN** и локальной сети.
   - Кнопка «Скопировать IP для друзей» в один клик.
   - Запуск `SkyrimTogetherServer.exe` прямо из окна программы.
6. **Безопасный откат («Вернуть чистый Skyrim»):**
   - Удаляет только файлы мода по манифесту, оставляя игру и сохранения чистыми.
7. **Сборка архива для друзей:**
   - Кнопка создания единого `.zip` бандла, который можно отправить друзьям в Telegram/Discord или выложить на GitHub.

## 🎮 Как играть с друзьями (Инструкция)

### Шаг 1. Подготовка игры
* Убедитесь, что у всех участников установлен чистый **Skyrim Special Edition** (версия 1.6+).
* **ВАЖНО:** Каждый игрок должен начать новую игру **в одиночку**, пройти обучение в Хелгене и выйти из пещеры наружу (например, дойти до Камней-Хранителей или Ривервуда).  
  *Скриптовая повозка в начале игры ломается в мультиплеере, поэтому пролог проходят соло!*

### Шаг 2. Запуск и установка
1. Запустите `SkyrimCoopLauncher.exe`.
2. Если путь к игре не определился автоматически, нажмите «Обзор...» и выберите папку со `SkyrimSE.exe`.
3. Нажмите кнопку **«⬇ Скачать и установить кооп-мод»** и дождитесь завершения шкалы.

### Шаг 3. Соединение (через Radmin VPN)
1. Создайте комнату в **Radmin VPN** и пригласите туда друзей.
2. **Хост (тот, кто держит мир):**
   - Переходит во вкладку **«🛡 Сервер для друзей»**.
   - Нажимает кнопку **«🛡 Запустить сервер»** (откроется окно консоли сервера, не закрывайте его).
   - Нажимает **«📋 Скопировать для друзей»** и отправляет свой Radmin IP друзьям.
   - Запускает игру через кнопку **«⚔ Играть»**.
   - В игре нажимает `F2` (или правый `Ctrl`), вводит `127.0.0.1` и подключается к своему серверу.
3. **Друзья (подключающиеся игроки):**
   - Запускают игру через кнопку **«⚔ Играть»**.
   - В игре нажимают `F2` (или правый `Ctrl`), вводят Radmin IP хоста и нажимают **Connect**.
   - Готово! Вы в одном мире.

### Шаг 4. Квесты
* В меню `F2` создайте группу (Party) и пригласите друзей.
* Назначьте **одного лидера группы**.
* **Только лидер** говорит с ключевыми сюжетными персонажами и берет задания, чтобы квесты синхронизировались корректно.
